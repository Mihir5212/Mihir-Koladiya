# Mihir Koladiya — Portfolio

Personal portfolio website: transportation engineering, road safety research, projects, publications and gallery.
Plain static site (HTML, CSS, vanilla JavaScript). No build step needed.

## Folder structure

```
├── index.html            # Homepage
├── about.html            # Professional profile
├── projects.html         # Projects listing
├── project-detail.html   # Individual project details
├── publications.html     # Research publications
├── insights.html         # Technical articles
├── insight-detail.html   # Individual article details
├── showcase.html         # Skills and achievements showcase
├── gallery.html          # Photo gallery
├── contact.html          # Contact page
├── css/style.css         # Complete website styling
├── js/
│   ├── data.js           # Central website content and data
│   └── main.js           # Website functionality and rendering
└── assets/
    ├── images/           # Profile, certificate and gallery images
    └── docs/             # CV, papers and reports (PDF)
```

## Run locally

Open `index.html` in a browser, or run `python -m http.server 8000` and visit http://localhost:8000.

## Deploy

GitHub Pages: **Settings → Pages → Deploy from branch → `main` / root**.
